# Next-CCS

> Connected Car Reservation Backend

동시 예약 환경에서 데이터 정합성을 보장하고,
대용량 예약 데이터의 조회 성능을 개선하는
차량 예약 백엔드 프로젝트입니다.

---

## 프로젝트 목표

- 차량 예약 시스템 구현
- 중복 예약 방지
- 동시성 제어
- 실행계획(EXPLAIN) 분석
- 인덱스 최적화
- 테스트 코드 작성
- Docker 배포

---

## 기술 스택

- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- Redis
- Docker
